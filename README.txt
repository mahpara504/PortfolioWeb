STUDENT PORTFOLIO SAMPLE
========================

FILES
- index.html: page content and Bootstrap layout
- style.css: custom design and responsive styling
- script.js: footer year and demo contact form interaction

HOW TO RUN
1. Extract this ZIP file.
2. Open the folder in Visual Studio Code.
3. Open index.html in a browser, or use the VS Code Live Server extension.
4. Internet is required for the Bootstrap CDN stylesheet and JavaScript.

TEACHING NOTES
- Start by reading the HTML structure from top to bottom.
- Explain that Bootstrap classes such as container, row, col-lg-7, navbar and btn provide layout/components.
- Explain that style.css customizes the design.
- Explain that script.js handles the demo form message and current year.
- The contact form is FRONT-END ONLY. It does not send email or save data.
- To make it a real form, students must add a PHP form handler, validate/sanitize input on the server, and use prepared statements to insert messages into MySQL.
